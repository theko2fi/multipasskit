# MultipassKit

MultipassKit is a multipass kit containing both an API to remotely manage multipass hosts and a multipass SDK.

## Features

- Manage Multipass instances and resources using a simple API.
- SDK for programmatic control of Multipass instances.
- Asynchronous task management using Celery.

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/theko2fi/multipasskit.git
    cd multipasskit
    ```

2. Create a virtual environment and activate it:
    ```sh
    python3 -m venv env
    source env/bin/activate
    ```

3. Install the required dependencies:
    ```sh
    pip install -r multipasskit/api/requirements.txt
    ```

4. Install the package:
    ```sh
    pip install .
    ```
